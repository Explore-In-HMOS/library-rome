# Changelog

## 1.0.0

First release: an ArkTS port of ROME at commit `6b4a7e8`.

- Parsing and generation of RSS 0.90 to 2.0, RSS 1.0, Atom 0.3 and 1.0, and OPML 1.0 and 2.0.
- Conversion between these formats through the `SyndFeed` model.
- Modules: Dublin Core, Syndication, content, slash, iTunes, Media RSS, GeoRSS, Atom links, OpenSearch, Creative
  Commons, Podlove Simple Chapters and threading.

See `README.md` for usage and for the differences from ROME.
